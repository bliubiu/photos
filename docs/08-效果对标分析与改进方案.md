# 08 - 效果对标分析与改进方案（vs HivisionIDPhotos / LiYing / BiRefNet 官方）

> 结论先行：效果差距**不是单一原因**，而是「模型预处理不匹配 + 抠图模型选型不当」两大根因
> （P0），叠加「裁剪构图逻辑过简」「mask 后处理偏激进」两个次因（P1）。以下所有对照结论
> 均已与参考实现源码逐项核对，非推测。

## 1. 对标基准

| 参考项目 | 用途 |
| --- | --- |
| Zeyi-Lin/HivisionIDPhotos | 抠图模型选型、预处理约定、裁剪构图（`photo_adjuster.py`、`human_matting.py`） |
| aoguai/LiYing | 姿态纠偏算法基准（本项目已复刻 0.6/0.4 融合，此项不构成差距） |
| ZhengPeng7/BiRefNet 官方 | BiRefNet 推理预处理权威口径（`dataset.py`） |

## 2. 根因分析

### 2.1 P0-①：抠图模型预处理与训练分布不匹配（最大嫌疑）

本项目对 BiRefNet/RMBG/MODNet 统一使用「letterbox（114 灰边）+ 仅 ÷255」，而参考实现均不同：

| 模型 | 本项目实现 | 参考实现（已核对源码） |
| --- | --- | --- |
| BiRefNet | letterbox 灰边填充 + ÷255 | **直接拉伸 resize 到 1024×1024** + ÷255 − mean(0.485,0.456,0.406) ÷ std(0.229,0.224,0.225)（BiRefNet 官方 `dataset.py` 与 Hivision `transform_image` 一致） |
| RMBG-1.4 | letterbox + ÷255 | resize 1024 + ÷255 后 **(x−0.5)/0.5 → [−1,1]**；输出再做 min-max 归一化 |
| MODNet | letterbox + ÷255 | resize 512 + **(x−0.5)/0.5 → [−1,1]** |

影响链条：
1. BiRefNet 训练时从未见过 114 灰边填充，且缺少 mean/std 归一化 → 输入分布整体偏移，
   mask 边缘发丝判定、背景置信度全面劣化（这是「发丝抠不干净 / 边缘发糊 / 底色残留」
   的直接来源）。
2. RMBG/MODNet 在 [−1,1] 之外的输入下输出 matte 会系统性异常（speed 模式受影响最重）。
3. letterbox 对 ~3:4 人像会在 1024 画布上留下约 25% 的填充区，进一步放大分布偏移；
   而参考实现用拉伸 resize，模型对轻微纵横比畸变是鲁棒的（训练即如此）。

已核对无问题的项：MoveNet ONNX 输入 [0,1]（与 aila-models 口径一致）；RetinaFace
减均值 (104,117,123) 已对齐 Hivision `retinaface/inference.py`。

**修复方案（P0，改动小、收益最大）**：
- 利用已有的声明式 `[models.<id>.preprocess]`，为三个抠图模型补上
  `norm = "mean_std"` 配置（BiRefNet 用 ImageNet mean/std；RMBG/MODNet 用
  mean=0.5/std=0.5 等价 (x−0.5)/0.5）。
- `Preprocess` 增加一个 `resize = "stretch" | "letterbox"` 声明（或对 `role = matting`
  默认 stretch），mask 逆变换随之简化为直接 resize 回原图（`probability_map` 已支持
  无 letterbox 路径）。
- 补一组回归测试：用纯色底人像图跑真实模型，断言背景区 matte 均值 < 0.1、
  主体区 > 0.9（当前错误预处理下这类断言大概率失败，可作为修复的前后对照）。

### 2.2 P0-②：抠图模型选型不是人像专用

- 本项目 `birefnet_lite` 下载的是 **BiRefNet-general-bb_swin_v1_tiny**（DIS5K 通用
  显著目标分割权重，tiny 骨干），`birefnet_full` 是 **BiRefNet-general-epoch_244**——
  两者都是「通用物体」模型，不是人像抠图模型。
- HivisionIDPhotos 默认走 `hivision_modnet`（人像专用、为纯色换底专门调优，
  且有 `hollow_out_fix` 轮廓修补），可选项还有 `modnet_photographic`、`rmbg-1.4`、
  `birefnet-v1-lite`。人像专用模型在发丝、衣物边缘、肩部轮廓上明显更稳。

**修复方案（P0）**：
- balanced/quality 的抠图模型改为 **BiRefNet-portrait**（ZhengPeng7 官方发布
  `BiRefNet-portrait-epoch_150.onnx`，ONNX 可直接替换），保留 general 版本作为
  「通用抠图」可选项。
- speed 模式引入 `hivision_modnet` 或 `modnet_photographic`（512 输入，CPU 也快），
  与 Hivision 默认口径对齐。
- 模型清单 `docs/04-模型清单.md` 同步更新下载地址与 sha256。

### 2.3 P1-①：裁剪构图逻辑过简（直接决定「像不像证件照」）

本项目 `workflow.rs`：头顶留白 = 0.2×脸高、下巴余量 = 0.1×脸高，宽按目标比例反推，
脸中心落在照片约 **54%** 高度处；一次裁剪成型，无位置校验。

Hivision `photo_adjuster.py`（已核对）：
1. 裁剪框面积 = 5 × 脸面积（`head_measure_ratio=0.2`），按标准尺寸等比放大；
2. **脸中心置于照片 45% 高度**（`head_height_ratio=0.45`）；
3. 两轮修正：人像左右有空隙则收紧裁剪框；**头顶距顶部比例限制在 [10%, 12%]**
   （`head_top_range=(0.12,0.1)`），超限自动平移；
4. 底部有空隙时人像下移贴底（`move`）；
5. 标准照用分级 INTER_AREA 缩小，另有 ≥600px 的 HD 照。

**修复方案（P1）**：复刻上述 `adjust_photo` 两轮裁剪：`head_height_ratio=0.45`、
`head_top_range=(0.12,0.1)`、底部贴底；把 0.2/0.1 两个常数移入配置并弃用。
同时输出口径对齐（标准照 + 高清照双产物）。

### 2.4 P1-②：mask 后处理偏激进 / 偏弱并存

- 羽化过渡带 `MASK_FEATHER_PX = 2px` 相对 1024+ 的大图几乎可忽略；闭运算半径 1px
  也太弱——Hivision 对 hivision_modnet 的 matte 专门做 `hollow_out_fix`
  （腐蚀找最大轮廓 + 泛洪填充补洞），本项目的「闭运算填孔」只覆盖 1px 级小孔。
- 距离场羽化把主体内部钳到 255、外部钳到 0，仅过渡带保留软 alpha：相比参考实现
  「模型 matte 直接当 alpha 用」（全程连续），发丝带的半透明层次会偏脆。

**修复方案（P1）**：feather/闭运算半径按图像宽度自适应（如 宽/512）；增加
最大连通域 + 泛洪填孔（复刻 `hollow_out_fix`，纯 Rust 可用 imageproc 实现）；
保留软阈值，但把骨架判定改为「软 alpha 加权」而非二值距离场骨架。

### 2.5 P2：其他次要差异

| 项 | 本项目 | 参考 | 建议 |
| --- | --- | --- | --- |
| 输入预缩放 | `max_input_side = 0`（不缩） | Hivision 统一最大边 2000 | 默认改 2000，降低耗时且对齐口径 |
| 主脸选择 | NMS 后取 first（最高分） | 取最大面积脸 | 多人场景按 面积×中心距 加权选主脸 |
| 美颜 | 默认关闭 | `beauty_face` 默认开启（美白/亮度/对比/锐化） | WebUI 默认开启轻量档 |
| 输出缩放 | Lanczos3 一步到位 | 分级 INTER_AREA | 降采样时改分级缩放（minor） |
| 换底合成 | alpha 混合 + 去色边 | 直接 paste + mask | 现有 decontaminate 是加分项，保留 |

## 3. 验证与量化方法（避免「感觉变好了」）

1. **A/B 对照**：同一输入图，仅切换预处理配置（P0-① 修复前后），导出 mask 透明底
   PNG 并排对比发丝与边缘。
2. **对拍指标**：以 Hivision 官方 Python pipeline 输出的 matte 为参照，计算本项目
   mask 与其的 IoU / 边缘带（±3px）均值差；目标 IoU ≥ 0.97。
3. **场景回归集**：收集 10 张典型困难样例（深色头发 vs 白底、灰衣 vs 灰底、
   侧光、戴眼镜），纳入 `photos-cli` 基准命令，输出指标表防退化。

## 4. 实施顺序

| 优先级 | 事项 | 预期收益 |
| --- | --- | --- |
| P0 | 抠图三模型预处理修正（mean_std + stretch resize） | 边缘/发丝质量大幅回升 |
| P0 | 抠图模型换 BiRefNet-portrait / hivision_modnet | 人像专用精度 |
| P1 | 裁剪复刻 adjust_photo 两轮构图 | 构图符合证件照标准 |
| P1 | mask 填孔 + 自适应羽化 | 无孔洞、边缘自然 |
| P2 | 预缩放 2000、主脸选择、默认美颜、分级缩放 | 稳定性与体验 |

P0 两项改动集中在 `preprocess.rs` / `config.rs` / `application.toml`，均为配置与
小函数改动，不动架构；P1 涉及 `crop.rs` / `workflow.rs` / `matting.rs` 的算法重写，
建议 TDD：先按 §3 指标定验收，再实现。

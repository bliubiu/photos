# 图像处理栈采用纯 Rust，弃用 OpenCV-RS

**状态：已接受。**

`AGENTS.md` 原定使用 OpenCV-RS 绑定做图像处理。经权衡决定改用纯 Rust 图像栈：`image` + `imageproc` 为底座，几何与张量运算用 `nalgebra`，双边滤波磨皮、兰索斯重采样、mask 精细化等缺失算子自研。

**考虑过的选项：**
- `opencv` crate：算法最全，可照搬 OpenCV 伪代码；但引入 C++ 工具链依赖，Windows 需 vcpkg/预编译，产物体积大，跨平台构建链不可预测，与「纯本地离线 + 编译优化减小体积」的约束冲突。
- `image` + `imageproc`：构建链纯净，三平台 `cargo build` 一致；代价是少数高级算子需自研，自研量估计在千行级，可控。

**后果：**
- pipeline 各步骤算子（仿射旋转、羽化、形态学、换底混合、裁切）以 `imageproc` 等价实现，缺失部分自研。
- 所有新代码禁止引入任何 C/C++ 图像库绑定。

## 1. 目的与边界

本文档是本项目 **ONNX 模型注册表的权威清单**，定义：

- 稳定 `id`（与 `application.toml` 的 `[models.<id>]`、`[modes.*]` 引用一致）
- 用途、默认路径、输入张量约定、所属预设
- 校验、放置、可选下载与许可证登记要求

边界：

- **处理链路零联网**；「一键下载」仅为可选前置便利（见 PRD 4.6）。
- 大文件不进 git（`.gitignore` 忽略 `models/`）；本清单只描述元数据。
- MODNet 兼容保留，**不进任何预设**；专业用户可改配置启用。

## 2. 注册表字段约定

`[models.<id>]` 必备字段（样例见 `docs/examples/application.toml`）：

| 字段 | 类型 | 说明 |
|---|---|---|
| `path` | string | 相对项目根或绝对路径的 `.onnx` 文件 |
| `sha256` | string | 64 位小写十六进制；定版前为占位全 0 |
| `input_dims` | int[] | 约定布局 `[N,C,H,W]` 或 NHWC（见下表「布局」列） |

可选字段：

| 字段 | 说明 |
|---|---|
| `download.url` | 单模型下载地址（可选） |
| `enabled` | 默认 true；false 时不参与校验与预设解析（预留） |

`[modes.<suite>]` 引用：

| 字段 | 含义 |
|---|---|
| `face` | 人脸检测模型 id |
| `keypoint` | 人体关键点模型 id |
| `matting` | 人像分割模型 id |
| `execution_provider` | `cpu` \| `cuda` |

## 4. 预设 → 模型映射

与 PRD「三套模式套件」、`application.toml` 的 `[modes.*]` 一致：

| 套件 | face | keypoint | matting | execution_provider |
|---|---|---|---|---|
| `speed` 极速 | `mtcnn` | `movnet_light` | `rmbg` | `cpu` |
| `balanced` CPU 高性能（默认） | `retinaface` | `movnet_light` | `birefnet_lite` | `cpu` |
| `quality` GPU 高质量 | `retinaface` | `movnet_thunder` | `birefnet_full` | `cuda` |

M1 最小闭环仅强制 **balanced** 三件套就绪；speed / quality 可后置下载。

## 5. 校验与状态

- **惰性校验**：首次使用某模型时计算 sha256；结果按 `路径 + mtime + size → sha256` 写入 `kv_cache`。
- 文件未变则跳过全量哈希（目标：缓存命中 < 100ms，见实施计划 M0）。
- 状态枚举（`photos models` 与 `GET /models` 一致）：

| check_status | 含义 |
|---|---|
| `ready` | 文件存在且 sha256 与注册表一致 |
| `cached_ok` | 缓存命中且路径/mtime/size 未变 |
| `missing` | 文件不存在 |
| `hash_mismatch` | 文件存在但 sha256 不一致 |

缺失或校验失败 → 提示「手动放置」或「一键下载」；**禁止**把未校验文件当作就绪。

## 6. 放置与可选下载

1. **手动放置（推荐，保持离线）**：按上表 path 放入 `项目根目录/models/`。
2. **可选下载**：`[models.download].enabled = true` 且模型配置了 `download.url` / 镜像 `base_url` 时，CLI/WebUI 可触发；下载后仍走完整 sha256 校验。

下载配置（`application.toml`）：

```toml
[models.download]
enabled = true
timeout_secs = 120
concurrency = 2
# base_url = "https://example.invalid/models"
```

离线环境保持 `enabled = false` 或不配置镜像即可。

## 8. 维护规则

- 新增模型：先改本文档总表与预设映射，再改 `docs/examples/application.toml`，最后实现装载代码。
- 更换模型文件：更新 `sha256`，清相关 `kv_cache` 键，同步 CHANGELOG。
- 删除/更名 id：属破坏性变更，需 ADR 或 CHANGELOG Breaking 段说明迁移方式。
- 禁止在文档或日志中粘贴完整模型二进制或未脱敏的绝对用户路径以外的敏感信息。
